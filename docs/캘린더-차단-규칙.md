# 실험실 차단 캘린더 규칙

과학실험실 사용 신청 시스템에서 특정 날짜의 실습실을 막는 방법.
전용 구글 캘린더에 일정을 만들고 **제목**을 규칙에 맞게 적으면 된다.

> 교원용 안내서(그림 포함): 이 문서와 같은 내용을 신규 교원이 읽기 쉽게 정리한 페이지가 별도로 있다.
> 규칙을 바꾸면 두 곳을 함께 갱신할 것.

관련 코드는 모두 `과학실험실 신청서/Code.gs`에 있다.

| 상수·함수 | 역할 |
|---|---|
| `LAB_CALENDAR_ID` | 차단 일정을 읽어 오는 캘린더 |
| `CANONICAL_LABS_` | 정식 실습실 이름 |
| `LAB_ALIASES_` | 약칭 → 정식 이름 |
| `FLOOR_GROUPS_` | 층·동 그룹 → 실습실 목록 |
| `parseNewBlockTag_` | `[차단]` 태그 파서 (권장 표기) |
| `matchBlockByWords_` | 자연어 표기 파서 (차단·불가·신청불가) |
| `parseCalendarEventForBlocks_` | 위 둘을 합쳐 이벤트 1건을 해석 |
| `getCalendarBlocks` | 하루치 이벤트를 집계 (30초 캐시) |
| `getUnavailableForDate` | 주말 자동 차단까지 반영한 최종 결과 |
| `previewCalendarBlocks` | 운영자용 진단 — 해석 결과 미리보기 |

## 기본 문법

```
[차단] 실습실 / 시간 / 사유
```

- **실습실** — 정식 이름·약칭·층 이름·`전체`. 쉼표로 여러 개
- **시간** — `ET` · `EP1` · `7교시` · `전체`. 쉼표로 여러 개. 생략하면 종일
- **사유** — 안내용. 판정에 영향 없음

일정의 **날짜**가 막히는 날이다. 일정의 시간대는 보지 않는다. 설명란도 제목과 동일하게 인식한다.

## 세 가지 유형

집계는 `getCalendarBlocks`에서 갈린다.

| 적은 내용 | 저장 위치 | 적용 범위 |
|---|---|---|
| 실습실만 | `blockedLabs` | 그 실 종일 |
| 시간만 | `blockedTimes` | 모든 실의 그 시간 |
| 실습실 + 시간 | `perLabTimes` | 그 실의 그 시간만 |
| `[차단]`만 | `allBlocked` | 그날 전체 |

## 층·동 그룹

`FLOOR_GROUPS_` 정의. **2026-08 개정으로 실제 건물 배치와 일치하도록 정리**했다.
개정 전에는 `3층`이 물리 계열(실제 2층)까지 막았다.

| 키워드 | 확장 결과 |
|---|---|
| `1층` `S동 1층` | 화학실험실 · 생물실험실 · 프로젝트실험실 · 첨단기기실험실 · 오픈랩 |
| `2층` `S동 2층` | 물리실험실 · 파동광학실험실 · AP Lab · IT 공학실 · 코딩실 · 멀티미디어실 |
| `3층` `S동 3층` | Tech & Art LAB |
| `2·3층` `2,3층` `2.3층` | 위 2층 + 3층 합집합 |
| `N동` | 가정실습실 · 융합기술실 · 창의공학실 · 공작기계실 · FAB Lab |
| `공학존` `공학ZONE` | 융합기술실 · 창의공학실 · 공작기계실 · FAB Lab |

가정실습실만 막으려면 `N동`이 아니라 `[차단] 가정실습실`로 실 이름을 직접 적는다.

### ⚠️ 그룹 키를 추가할 때

`expandFloorGroups_`는 **공백 제거·소문자화한 본문에 키가 포함되면 매칭**한다.
개별 실습실 이름의 부분문자열이 되는 키를 넣으면, 실 하나만 막으려던 입력이 그룹 전체로 번진다.

- `공학` → `창의공학실`의 부분문자열이라 **넣으면 안 된다**
- `공학존` → 어느 실 이름에도 포함되지 않아 안전

`parseNewBlockTag_`는 토큰마다 그룹 확장을 **먼저** 시도하고, 성공하면 실 이름 정규화를 건너뛴다.
키를 추가하면 반드시 `CANONICAL_LABS_` 전체와 대조할 것.

## 자동 차단

`getUnavailableForDate`에서 캘린더와 무관하게 적용된다.

- **주말** — 토·일요일은 ET·EP1 자동 차단
- **지난 날짜** — `submitApplication_`에서 거부
- **7교시** — 화요일 + 사용목적 `동아리 활동` + 7교시 단독 선택일 때만 노출 (`isSeventhCheckedAndValid_`)

## 자연어 표기 호환

`[차단]` 태그 없이도 **차단 · 불가 · 신청불가** 중 한 단어가 있으면 인식한다
(`matchBlockByWords_`). 예: `1층 차단`, `화학실험실 ET 신청불가`.

차단 단어가 없으면 실 이름이 언급돼도 **막히지 않는다.** v3.58에서 의도적으로 바꾼 동작으로,
그 전에는 실 이름 언급만으로 종일 차단되고 `Meeting` 같은 영단어 속 `ET`까지 잡혔다.

## 반영 시점

- `getCalendarBlocks`는 날짜별 30초 캐시
- 학생 **제출 시점**에는 `getUnavailableForDate(date, true)`로 캐시를 우회해 캘린더를 다시 읽는다.
  급하게 막아도 그 이후 접수는 확실히 차단된다

## 이름이 바뀐 실습실

- `컴퓨터실` → **`IT 공학실`** (2026-08). 옛 이름은 `LAB_ALIASES_`로 계속 인식된다
- `멀티미디어실` — 신청 접수 중단 상태. 이름 정규화·캘린더 차단·담당교사 시트 키 용도로만 남아 있다.
  `CANONICAL_LABS_`에서 지우면 코딩실·IT 공학실의 담당 안내 조회가 깨진다

## 확인 방법

```javascript
previewCalendarBlocks('2026-09-01')
```

신청서 Apps Script 편집기에서 실행하면 그날 이벤트가 각각 어떻게 해석됐는지,
최종적으로 어느 실·어느 시간이 막히는지 로그로 출력된다. 교사·관리자 계정만 실행 가능하다.

제목을 잘못 적어도 오류가 나지 않고 조용히 안 막히므로, 중요한 차단은 반드시 확인할 것.
