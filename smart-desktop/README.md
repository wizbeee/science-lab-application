# 📚 스마트 바탕화면 v2.6.0
> 교사·직장인을 위한 AI 통합 대시보드 (Windows 데스크톱 앱)

---

## 🚀 설치 방법

1. `스마트 바탕화면 Setup 2.x.x.exe` 실행
2. 설치 완료 후 바탕화면 아이콘 더블클릭으로 실행
3. 최초 실행 시 온보딩 화면에서 기본 정보 입력

---

## ⚙️ 개인 설정 필수 항목

앱 우측 상단 **⚙️ 설정** 버튼을 클릭하여 각 탭에서 아래 항목을 설정하세요.

### 1. 🌤️ 날씨 설정 (`설정 → 날씨`)

| 항목 | 설명 | 예시 |
|------|------|------|
| 위치 이름 | 표시할 도시 이름 | `수원`, `대전`, `아산` |
| 위도 | 해당 지역 위도 (소수점 4자리) | `37.2636` |
| 경도 | 해당 지역 경도 | `127.0286` |

> 위도·경도는 [Google Maps](https://maps.google.com) 에서 위치 마우스 우클릭 → 좌표 복사

---

### 2. 🍱 급식 설정 (`설정 → 급식`)

NEIS(나이스) 학교 코드를 입력해야 급식 정보가 표시됩니다.

| 항목 | 설명 | 찾는 방법 |
|------|------|----------|
| 교육청 코드 | 시도교육청 코드 2~3자리 | 아래 표 참고 |
| 학교 코드 | 학교 고유 코드 | NEIS 공공데이터 포털 또는 앱 내 검색 |

**시도교육청 코드 목록**

| 코드 | 교육청 | 코드 | 교육청 |
|------|--------|------|--------|
| B10 | 서울 | J10 | 충남 |
| C10 | 부산 | K10 | 전북 |
| D10 | 대구 | L10 | 전남 |
| E10 | 인천 | M10 | 경북 |
| F10 | 광주 | N10 | 경남 |
| G10 | 대전 | O10 | 제주 |
| H10 | 울산 | P10 | 세종 |
| I10 | 경기 | R10 | 강원 |

> 학교 코드 확인: [NEIS Open API](https://open.neis.go.kr/portal/mainPage.do) → 학교기본정보 검색

### 3. 🔗 Google 연동 (`설정 → 연동 → Google`)

Google 캘린더·Gmail·Drive 기능 사용을 위한 OAuth 인증.

#### 사전 준비 (Google Cloud Console)
1. [Google Cloud Console](https://console.cloud.google.com) 접속
2. 새 프로젝트 생성
3. `API 및 서비스` → `사용자 인증 정보` → `OAuth 클라이언트 ID` 생성
   - 애플리케이션 유형: **웹 애플리케이션**
   - 승인된 리디렉션 URI: `http://localhost:3000/auth/google/callback`
4. 생성된 **클라이언트 ID** 와 **클라이언트 비밀번호** 복사

#### 앱 내 입력 방법
- 설정 → 연동 탭 → Google → `클라이언트 ID` 입력 → `Google 로그인` 버튼 클릭

> **참고:** `src/renderer/components/SettingsPanel.jsx` 및 `Onboarding.jsx` 내
> `GOOGLE_CLIENT_SECRET` 상수를 본인의 클라이언트 비밀번호로 교체하면
> 매번 입력하지 않아도 됩니다.

### 5. 📢 전광판 설정 (`설정 → 전광판`)

Google Sheets를 전광판 데이터로 활용합니다.

#### Google Sheets 형식
| A열 (내용) | B열 (순서) |
|-----------|-----------|
| 오늘 3교시 자습 | 1 |
| 내일 전교 조회 09:00 | 2 |
| 과학실 청소 완료 요망 | 3 |

#### 설정 방법
1. Google Sheets 문서 생성 → 위 형식으로 입력
2. `파일` → `공유` → `링크가 있는 모든 사용자 (뷰어)` 설정
3. 공유 URL 복사 → 앱 설정 → 전광판 URL 입력

---

### 6. 🕐 수업 시간표 설정 (`시간표 위젯`)

#### 직접 입력
- 시간표 위젯 내 각 셀 클릭 → 과목·학급·장소 입력

#### CSV 파일로 가져오기
시간표 위젯 상단 **📂 CSV** 버튼 클릭

**CSV 형식 예시:**
```
교시,월,화,수,목,금
1,화학I 2-1,화학I 2-2,화학I 2-3,,
2,화학탐구실험,화학탐구실험,,화학I 2-4,
3,,,화학탐구실험,화학탐구실험,화학I 2-5
4A,점심,점심,점심,점심,점심
4B,화학II,화학II,,화학II,화학II
5,,,화학탐구실험,화학탐구실험,
```

- 첫 행은 헤더 (자동 인식)
- A열은 교시 번호 (`1`, `2`, `3`, `4A`, `4B`, `5`~`7`)
- `점심` 셀은 자동으로 점심 아이콘으로 표시

## 🔧 트러블슈팅

### Google 로그인 오류 "client_secret is missing"
→ `SettingsPanel.jsx`의 `GOOGLE_CLIENT_SECRET` 을 본인 OAuth 클라이언트 비밀번호로 교체

### 급식 정보가 표시되지 않음
→ 설정 → 급식에서 교육청 코드·학교 코드가 올바른지 확인

### AI 응답이 영어로 나옴
→ 설정 → AI Plus에서 시스템 프롬프트를 한국어로 응답하도록 수정

### 캘린더에 Google 일정이 표시되지 않음
→ 설정 → 연동 → Google → "표시할 캘린더 선택" 에서 캘린더 체크박스 활성화
