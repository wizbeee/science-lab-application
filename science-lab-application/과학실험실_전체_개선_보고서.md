| B-4 | updateApplicationStatus 동시성 보호 없음 | 🔴 | 570행: 동일. 두 관리자가 같은 건을 동시에 수정하면 데이터 충돌 |

| B-7 | updateChemicalRecords 폐기 방법 열 누락 | 🟡 | 694행: appendRow에 14개 항목 중 '폐기 방법' 필드가 빠져 있음. 신청 프로그램의 시약 기록과 컬럼 불일치 발생 가능 |

| B-9 | getApplicationStats 전체 데이터 2회 로드 | 🟡 | 510행: getApplicationStats이 getAllApplications를 호출하여 전체 데이터를 로드하고 통계만 계산. 초기 로딩 시 전체 데이터+통계로 2번 호출 가능 |
