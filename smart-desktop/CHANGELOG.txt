=========================================
  스마트 바탕화면 - 버전 변경 이력
=========================================

[v2.6.0] 2026-03-30
-----------------------------------------
신규 기능
  - 전광판 위젯 완전 리디자인
    · LED 스타일 제거 → 테마 색상 기반 pill 형태 디자인
    · position: fixed 오버레이 방식 (레이아웃 밀림 없음)
    · 너비 calc(100vw - 120px), 상단 중앙 배치
    · 고정(📌) 버튼: 마퀴 일시정지/재개
    · 닫기(✕) 버튼 추가
    · Google Sheets A열 = 표시 텍스트, B열 = 정렬 순서 (오름차순)
  - Google 캘린더 선택 기능 개선
    · 기본 캘린더 자동 적용 제거 → 사용자가 직접 캘린더 선택
    · 선택된 캘린더 없을 시 경고 UI 표시
    · 기존 저장 데이터 자동 마이그레이션 처리
  - 시간표 위젯 열 너비 최적화
    · 교시 열: 기존 대비 절반 (7%)
    · 요일 열: 균등 분배 (각 18.6%)
    · 셀 내용 말줄임표(ellipsis) 처리 추가
  - Gmail 새 메일 알림 기능
    · 5분 주기 폴링, 새 메일 수신 시 데스크톱 알림
  - D-Day 위젯 자동 정리
    · 경과 2일 초과 항목 자동 삭제

수정 사항
  - 전광판 서비스: A/B열 역할 교정 (기존 반대였던 오류 수정)
  - 볼륨 제어 IPC: waveOutSetVolume(winmm.dll) 방식으로 교체
  - 태스크바 IPC: SHAppBarMessage + Base64 인코딩 방식으로 안정화
  - Drive 아이콘: 📁 → ☁️

초기화 데이터 정리
  - 날씨 기본값: 서울 (개인 정보 제거)
  - 급식 기본값: 빈값 (개인 학교 코드 제거)
