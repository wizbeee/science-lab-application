💡 바이브 코딩이 뭔가요?

전통적인 코딩은 문법을 외워서 직접 코드를 작성합니다. 하지만 바이브 코딩은 자연어(우리말)로 원하는 걸 설명하면 AI가 코드를 만들어줍니다.

여러분이 배울 것은 "어떻게 말해야 원하는 결과가 나오는가"입니다. 이것이 바이브 코딩의 핵심 기술이에요.

🔑 Claude API 키

API 키를 입력하면 AI가 여러분의 프롬프트를 자동으로 채점합니다.
없어도 연수 진행이 가능해요. 키는 이 브라우저에만 저장됩니다.

API 키 발급 방법 보기 →
  1. console.anthropic.com 접속
  2. 회원가입 (Google 로그인 가능)
  3. 좌측 메뉴에서 API Keys 클릭
  4. Create Key 버튼 클릭 → 이름 입력 → 생성
  5. 생성된 키를 복사해서 위에 붙여넣기

💰 신규 가입 시 무료 크레딧이 제공됩니다. 연수 전체 완주 시 약 $0.1~0.3 예상.
